# Keyboard Shortcuts

## Global

| Shortcut | Action |
|---|---|
| `⌘ N` | New meeting (ad-hoc, starts recording) |
| `⌘ ,` | Open Settings |
| `⌘ F` | Search across all meetings |
| `⌘ K` | Open Ask Anything (global chat) |
| `⌘ W` | Close window |
| `⌘ Q` | Quit Meeting Manager |

## Recording

| Shortcut | Action |
|---|---|
| `⌘ R` | Start / Stop recording |
| `Space` | Pause notepad scroll (while focused on transcript) |

## Sidebar Navigation

| Shortcut | Action |
|---|---|
| `⌘ 1` | Home |
| `⌘ 2` | Daily Brief |
| `⌘ 3` | Ask Anything |
| `⌘ 4` | People |
| `⌘ 5` | Search |
| `⌘ 6` | Analytics |
| `⌘ 7` | Activity |

## Meeting Detail View

| Shortcut | Action |
|---|---|
| `⌘ E` | Edit meeting title |
| `⌘ ↑` | Previous meeting |
| `⌘ ↓` | Next meeting |
| `⌘ T` | Toggle full transcript view |
| `⌘ Shift R` | Re-run AI (regenerate summary) |

## Notepad / Editor

| Shortcut | Action |
|---|---|
| `⌘ B` | Bold |
| `⌘ I` | Italic |
| `⌘ Shift K` | Insert checkbox (action item) |

## Ask Anything Chat

| Shortcut | Action |
|---|---|
| `⌘ ↩` | Send message |
| `⌘ N` | New conversation |
| `⌘ K` | Clear current chat |

## People Tab

| Shortcut | Action |
|---|---|
| `⌘ F` | Focus search |
| `↑` / `↓` | Navigate person list |
| `↵` | Open detail pane |

---

## Menu Bar Popover

The Meeting Manager menu bar icon opens a compact popover with:

- Active meeting / recording status
- Today's remaining meetings
- Quick "Start recording" button
- Model download progress (during initial WhisperKit download)

Click the icon to toggle the popover. Right-click for the system menu (Quit, Open Settings, etc.).
